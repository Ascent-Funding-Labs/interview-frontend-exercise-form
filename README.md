# User Registration

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/Ascent-Funding-Labs/interview-frontend-exercise-form)

A multi-step user registration form supporting personal, business, and enterprise account types.

## Setup

### Prerequisites
- Node.js 16+ and npm
- Your preferred code editor
- Chrome/Firefox with DevTools

### Installation

```bash
npm install
npm run dev
```

The app will open at http://localhost:5173

## Tech Stack

- React 18
- TypeScript
- Vite

## During the Interview

Your interviewer will walk you through what they'd like you to look at. Feel free to ask clarifying questions, use any tools you'd normally use (AI assistants, documentation, DevTools), and think out loud as you work.
